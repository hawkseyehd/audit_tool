# DataForSEO Business Listings Provider Policy

## Approval

DataForSEO Business Listings Search Live is the only live provider approved for Feature 30.
The integration uses the documented JSON API and must never scrape DataForSEO, Google Search,
Google Maps, a directory, or a social network.

- Provider ID: `dataforseo-business-listings`
- Terms review version: `reviewed-2026-07-25`
- Search endpoint: `POST /v3/business_data/business_listings/search/live`
- Credentials: `DATAFORSEO_LOGIN` and `DATAFORSEO_PASSWORD`

## Permitted Fields

Only these public business fields may be imported:

- Provider record ID (`place_id`, then `cid` or `feature_id` as a fallback).
- Business name.
- Primary category.
- Public website URL and normalized domain.
- Public business phone.
- Street address, locality, region, postal code, and country code.
- Provider check URL used as source provenance.
- Provider `last_updated_time`.
- Collection timestamp generated by this application.

Ratings, reviews, photos, logos, descriptions, opening hours, popularity, coordinates, and
individual contact details are not persisted.

## Limits and Cost Controls

- Campaign result limit: 1 to 5,000 records.
- Provider page limit: 1,000 records.
- Maximum provider calls per campaign: 5.
- One provider request at a time.
- Minimum 500 ms delay between provider calls.
- Request timeout: 30 seconds.
- Maximum retries per provider page: 3.
- Retry only HTTP 408, 429, and 5xx responses or transient network failures.
- Exponential backoff: 500 ms, 1 second, then 2 seconds.
- Cancellation is checked during requests, delays, retries, imports, and between pages.
- The UI must state that live execution is a paid provider operation before submission.

## Search Behavior

- Country is a required two-letter ISO code.
- Region and locality are optional exact geographic filters.
- Category is a DataForSEO business category slug; spaces are normalized to underscores.
- Keywords are applied as bounded title or category filters only when present.
- Radius is available only with explicit latitude and longitude and is sent as
  `latitude,longitude,radiusKm`.
- Website-required campaigns discard records without an HTTP or HTTPS website.
- Exclusions are case-insensitive phrases applied to business name, domain, and address.

## Retention and Provenance

- Imported source records use a conservative 30-day retention period.
- Each imported field names DataForSEO as its provenance.
- Suppression tombstones remain durable and are checked before import.
- Continuation tokens are stored only for campaign resumption and are cleared on completion.
- Authorization values and raw provider responses must never be persisted or logged.

## Production Review

Before commercial production use, the account owner remains responsible for confirming the
current DataForSEO subscription, pricing, API terms, permitted use, and any contract-specific
retention requirements. If those terms conflict with this policy, disable the provider until this
document and the adapter are updated.
